# Заголовок первого уровня

## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта

#### Что такое Markdown?
Markdown — это лёгкий язык разметки, используемый для быстрого и простого оформления текстовых файлов, документации и отчётов.

#### Где он применяется?
Он широко применяется на GitHub, в Obsidian, для создания README-файлов, на форумах и в различных системах управления версиями.

#### Зачем он нужен разработчикам?
Он позволяет писать легко читаемый код, который автоматически рендерится в красивый HTML/PDF, экономя время на визуальном форматировании.
